# 🎮 Mini Game Hub - Kelas VII Bilal

Koleksi mini game seru untuk Kelas VII Bilal bin Rabbah!

## Games Available

### 1. 🐦 Flappy Kelas
**Path**: `/page/minigame/flappy/`

Terbang menembus rintangan seperti pipa, hindari tabrakan, dan capai skor tertinggi!

**Features:**
- Canvas-based game dengan physics engine
- Collision detection
- Local leaderboard (Top 5)
- Sound effects
- Dark mode
- Responsive

**Controls:**
- SPACE / CLICK = Jump
- Hindari pipa

---

### 2. ❓ Quiz Cepat Kelas
**Path**: `/page/minigame/quiz/`

Tebak jawaban 5 soal tentang Kelas VII Bilal dalam 30 detik per soal!

**Features:**
- 5 soal random tentang kelas
- Timer 30 detik per soal
- Auto-skip jika timeout
- Score tracking
- Performance feedback
- Sound effects
- Dark mode

**Controls:**
- CLICK jawaban
- Auto-next jika timeout

---

## 🚀 Quick Start

1. **Dari Beranda**: Klik card "Mini Game"
2. **Atau langsung**: Visit `/page/minigame/`
3. Pilih game yang ingin dimainkan
4. Enjoy! 🎉
